A SMALL SIGNAL BOT

reminders for
Signal groups.

snorse-bot keeps reminders and reads shared calendars. It responds to explicit commands in groups or DMs and otherwise stays in its shell.

how to use itself-hosting guide

what does it do?

  • group and private reminders
  • recurring daily or weekly reminders
  • read-only Google Calendar lookups
  • scheduled calendar digests
  • short, scope-local reminder IDs

command reference →

group> @snorse-bot reminders

shared bot

Add @snorse-bot by Signal username. The public host is maintained for you and admits new groups when it has safe capacity.

setup and admission details →

self-host

Bring a separate Signal-capable number, Docker, and a machine you control. SQLite is included. Google Calendar is optional.

installation guide →

privacy

A Signal bot is trusted software: transport is encrypted, but the bot host processes command plaintext. Know the boundary.
