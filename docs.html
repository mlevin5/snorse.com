MAN PAGES FOR HORSES

command documentation.

Commands are forgiving of harmless punctuation and always scoped to the group or private conversation where they belong.

prefixes

place accepted ignored
group real mention or leading 🐴 ordinary conversation
direct message mention, typed @snorse-bot, or 🐴 unprefixed DM

reminders

remind [me/us] WHEN to THING

Create a one-time reminder using natural dates and times.

remind [me/us] every DAY at TIME to THING

Create a daily or weekly recurring reminder.

reminders list

List visible reminders. DM aggregation only includes groups where the sender is currently a member.

cancel #ID

Delete a reminder using its short local ID.

edit #ID ...

Change a reminder. Optimistic versions prevent silent overwrites.

calendar

calendar link <calendar id>

Link a readable Google Calendar to this scope.

calendar

Show upcoming calendar items.

calendar next 2 weeks

Choose a range from 1–93 days, or ask for this month.

Calendar access is read-only. All-day events are ignored. Without Google credentials, reminders keep working.

scope + delivery semantics

  • Every reminder belongs to one group or personal scope.
  • There is no default “main group.”
  • Short IDs may repeat across groups but stay unique inside one scope.
  • Inactive-group deliveries pause without erasing state.
  • Mutation batches receive one reaction plus concise combined errors.

troubleshooting

The bot did nothing.
Use a real mention or start with 🐴. Check capacity if this is a new group.
My DM was ignored.
Direct messages require an explicit prefix by design.
Calendar is not configured.
The host lacks Google credentials. Reminders still work.
Why can’t a DM see every group?
It only aggregates groups whose current Signal roster contains the sender.
